# Code of Conduct

## Our Standard

We expect contributors to interact respectfully and constructively.

Examples of positive behavior include:
- giving actionable, technical feedback
- assuming good intent
- focusing disagreement on design and implementation rather than people
- helping keep security-sensitive discussions responsible and calm

Examples of unacceptable behavior include:
- harassment, intimidation, or personal attacks
- publishing private or security-sensitive details irresponsibly
- disruptive conduct that blocks collaboration

## Scope

This applies to repository discussions, pull requests, issues, code review, and any project-managed community spaces.

## Enforcement

Project maintainers may remove comments, close threads, or limit participation when conduct breaks these rules.
