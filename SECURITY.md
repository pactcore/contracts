# Security Policy

## Supported Branch

Security fixes are applied to the `main` branch.

## Reporting a Vulnerability

Please do not open a public issue for a security vulnerability.

Instead:
- email the maintainers or security contact used by the PACT project, or
- open a private security advisory through GitHub if you have access.

When reporting, include:
- a clear description of the issue
- affected contracts and functions
- reproduction steps or proof of concept
- severity assessment and any suggested mitigation

We will acknowledge reports as quickly as possible, validate impact, and coordinate a fix before public disclosure.

## Disclosure Guidance

Please avoid publishing exploit details until a fix or mitigation is available for users.
